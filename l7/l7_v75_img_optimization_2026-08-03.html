3. Hallazgos transversales

  • liv-ing.com = peor caso aislado: 2 archivos legacy (mapa.gif + img_sec3.png) suman 2.68 MB = 60% del ahorro total del holding. Convertir esos 2 = ~1.2 MB savings en 1 commit.
  • mf3 + terracotta: 9/9 imágenes legacy JPEG/PNG — sin plugin ShortPixel/Imagify. Conversión batch beneficiaría a ambas.
  • dindonliving: plugin ShortPixel activo confirmado (4/5 ya WebP). Único residuo PNG = Banner1. Es la marca mejor optimizada a pesar de tener el HTML más pesado (theme Movedo, 505 KB).
  • Caveat GIF animado: mapa.gif es GIF89a — Google sugiere que puede ser animado (clickable o rotador). Validar UX en navegador antes de convertir a WebP estático: si es animación, requiere WebP animado o MP4.

🔴 Opción C — AVIF + <picture> fallback (~2-4 h, 2.63 MB)

  • ✅ Máximo savings (−44.3%)
  • ✅ Moderno / future-proof
  • ⚠️ 2-4 h Dani + riesgo regresión si no se prueba

Mi voto: A → B escalado. Primero A (validar GIF animado + arrancar producción real), si confirma escalado a B.
